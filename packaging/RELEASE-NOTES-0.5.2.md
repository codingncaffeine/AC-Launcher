## What's New

- **Several clients at once** — tick more than one account and press Launch to play them side by side. Each extra client runs in its own copy of the Wine prefix, so the game's "a client is already running on this machine" check no longer stops the second one. A copy is made once and reused, and settings and key maps changed in the first client carry over.
- **Stop one client at a time** — each running client is followed on its own, so stopping one closes only that game and the others keep playing.
- **Choose an account's servers from the Servers window** — every server now has "Launch on this server with" checkboxes for your accounts, and each account has an "Add or remove servers" button that opens it.

Install: the tarball, the .deb, or `ac-launcher-bin` from the AUR.
