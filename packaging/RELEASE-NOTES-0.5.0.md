## What's New

- **Accounts and multi-launch** — save any number of accounts, tick the servers each one plays on, and launch them all with one click or F5. Clients start one after another with a configurable pause, and each running client can be stopped on its own.
- **Server lists** — the community server lists are downloaded and cached, so the launcher still works offline. Add your own servers, copy a published one to customise it, or hide the ones you never use.
- **Server status** — every server is checked in the background and shown as up or down, with its response time.
- **Proton without Steam** — the game client runs through umu-launcher and Proton, with no Steam install needed. Pick any version of GE-Proton or UMU-Proton, from the latest back to older releases, or follow the latest automatically; downloads are verified against their published checksums, and Proton builds already on your computer can be used too.
- **Point it at your game folder** — choose your Asheron's Call folder with a folder picker, and the launcher checks it for the game client and its data files and tells you what is missing.
- **Windowed start** — the client can be set to start in a window, which avoids the fullscreen DirectX error many systems hit on first launch.
- **Log window** — everything the launcher, umu-launcher and Proton report, in one place.

Install: the tarball, the .deb, or `ac-launcher-bin` from the AUR. The first launch downloads the Proton runtime and your chosen Proton version, about 1 GB, once.
